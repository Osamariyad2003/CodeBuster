# CodeBuster Demo Script

Target length: 2-3 minutes.

## 0:00 - Hook

"CodeBuster is an AI-powered developer tool that turns GitHub code review noise into a prioritized engineering health workflow."

Show the landing page and explain that the project fits the Developer Tools track.

## 0:20 - Connect A Repository

Sign in with GitHub or show the connected repositories view.

"Instead of configuring separate scanners and dashboards, a team connects a repository and lets CodeBuster review every push or pull request."

## 0:45 - Repository Health

Open a repository dashboard.

Point out:

- overall health score,
- category scores,
- issue counts,
- review history,
- trend and monitoring widgets.

"The goal is not just to find warnings. It is to make the health of the codebase visible and trackable."

## 1:15 - AI Review Result

Open a completed review.

Show:

- AI executive summary,
- top risks,
- suggested fix order,
- severity/category filters,
- AI coverage badge.

"CodeBuster runs deterministic tools first, then uses the AI reviewer to reason over the evidence, rank the most important issues, and explain what should happen next."

## 1:50 - Finding Detail

Open a finding drawer.

Show:

- file and line,
- evidence,
- code snippet,
- AI explanation,
- suggested fix or preview.

"The reviewer gets the exact context and a concrete recommendation instead of a vague lint message."

## 2:20 - Fix Workflow

Show Fix Sprint or the Agents page.

"For fixable issues, CodeBuster can generate a patch workflow and group the top fixes into one reviewable pull request."

## 2:45 - Codex/GPT-5.6 Note

"This submission was built with Codex during OpenAI Build Week. Codex helped inspect the codebase, implement the analyzer and dashboard work, debug tests, and prepare the final submission materials. The product itself is also designed around AI-assisted code review, with configurable OpenAI/GPT-5.6-backed reasoning plus deterministic fallbacks."

End on the review dashboard or Agents page.
