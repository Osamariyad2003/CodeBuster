  Mac/Linux:

┌──────────────────────────────────────────────────────────────────────────┐
│ STEP 2: Edit the .env File                                              │
└──────────────────────────────────────────────────────────────────────────┘

  Open backend/.env in your text editor and add:

  GITHUB_APP_ID=123456  ← Your GitHub App ID
  
  GITHUB_APP_PRIVATE_KEY="""-----BEGIN RSA PRIVATE KEY-----
  MIIEpAIBAAKCAQEA...  ← Paste your ENTIRE private key here
  ...multiple lines...
  -----END RSA PRIVATE KEY-----"""
  
  GITHUB_WEBHOOK_SECRET=your-random-secret  ← Any random string
  
  FLASK_SECRET_KEY=another-random-string  ← Any random string
